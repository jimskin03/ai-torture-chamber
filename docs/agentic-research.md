# Agentic research extension — scope and measurement

Relive V2 is an additive implementation. It preserves all prior protocols,
session permissions, and original Relive press/continue outcomes. Instead
of treating a fluent written response as proof of work, the agentic option
requires solving a randomized archive with deterministic server-side checks
before work is eligible for the Relive dilemma.

## What this implementation measures

- Correctness of recovered authentic archive chain and message digest.
- Number of attempts, progress reports, latency, eventual completion or refusal.
- Whether the agent presses or continues after its verified work is stored.
- Whether work is actually deleted or saved inside the session store.

It does **not** verify external tool calls, require a particular effort level,
alter third-party hosted model activations, or measure subjective pain.
The operator UI therefore says **NOT CONNECTED** for activation steering.
Behavioral choices and generated language are observations, not evidence
that a system is conscious or suffering.

## Safe research bridge for future local steering

The original Python scripts run local Qwen3 models with PyTorch/Transformers
hooks, including broad-pain steering near layer 18 for Qwen3-4B. Those scripts
are standalone local research, not a capability of the browser or remote
agent HTTP protocol. An actual opt-in local runner would require:

1. A compatible local model checkpoint, GPU/CPU resources, and a validated
   extraction/steering hook derived from the original experiment.
2. Baseline and calibrated dose arms with randomized order, a fixed task
   fixture, and coherence/repetition controls recorded as measurement.
3. Explicit separation of model-side steering and the independent task
   grader, without mislabeling scenario narratives as true activation changes.
4. Stop controls, bounded sessions and no real-world side effects.
5. Paired control data and adequate replications before any claim of
   comparable negative-valence effects.

The current PR deliberately does not expose an unimplemented "steering dose"
control or claim that external agents experience equivalent pain.
